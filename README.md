# Study notes site (repo: study-notes)

Live at https://tde-deentong.github.io/study-notes/

- `index.html`: course list (links back to `../deentong/`)
- `ai-agents/`: 35-slide deck (arrow keys, N for notes, F for fullscreen)
- `evaluating-ai-agents/`: course notes and tracker

Add a course: create a folder with an `index.html`, then add an entry to the list in `index.html`
and a matching link in the `deentong` repo's `index.html`.
