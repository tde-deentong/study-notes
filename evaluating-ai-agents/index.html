What I will learn

  • Add observability to an agent so each decision step can be debugged.
  • Tell apart evaluating LLM systems and evaluating traditional software.
  • Design component-level evals with code-based checks and LLM-as-a-Judge.
  • Run structured experiments to improve agent performance.
  • Monitor agent behavior in production.
